# knowhere

Personal Claude Code plugin marketplace for bruk-io projects.

## What is knowhere?

knowhere is a plugin marketplace for [Claude Code](https://claude.com/claude-code). It carries the plugins that hold how I build software.

## Available Plugins

| Plugin | Category | Description |
|--------|----------|-------------|
| **authoring-kit** | development | Authoring Claude Code extensions: choosing the extension type, the judgement for each, a linter, a rule-delivering hook and an auditor agent |
| **c4-architecture** | development | Orthodox C4 architecture diagrams in LikeC4: component extraction from a codebase, a C4 linter with an edit hook, and publishing the viewer |
| **philosophy** | development | How Bruk builds software: standing constraints, code, Python and test rules, and a self-running loop of intent, spec, build and review |

The philosophy plugin's loop runs from an intent to a merged change; see [the self-running loop](https://github.com/bruk-io/knowhere/tree/main/intent/self-running-loop).
